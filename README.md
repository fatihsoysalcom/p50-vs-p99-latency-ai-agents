# P50 vs P99 Latency AI Agents

This Python script simulates AI agent response times, demonstrating how P50 (median) latency can be misleading in the presence of outliers, while P99 latency accurately reflects the experience of the slowest requests. It highlights the importance of P99 for performance-critical applications.

## Language

`python`

## How to Run

Save the code as `latency_demo.py` and run it from your terminal using `python latency_demo.py`.
